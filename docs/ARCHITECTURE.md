# 制造运营管理系统架构说明

## 分层结构

```text
Vue 3 管理端 / 响应式业务端
          │ HTTPS / JSON
Spring Security → Controller → Service / Domain Rule → JPA Repository
          │                         │
      权限与审计              MySQL 8 / 外部适配器
```

- 表现层：运营看板、生产执行中心、模块台账、规则工作台、企业控制中心、审计和设置。
- 接口层：Bean Validation、统一响应、异常映射、角色权限和跨域控制。
- 领域层：制造主数据、生产订单、排产下达、工序执行、在制品、物料消耗、质量关卡、设备安灯、班次交接、产品追溯与OEE分析，以及专属决策评分和处置动作。
- 数据层：生产订单聚合根、只增生产事件台账、JPA 乐观锁、唯一业务编号、控制项幂等键和审计时间线。
- 集成层：仅定义 `ERP_MES_IOT` 等外部系统引用和回执，不保存真实密钥。

## 部署边界

单机演示由 Docker Compose 启动 MySQL、后端和 Nginx 前端。正式生产应外置数据库与对象存储，接入企业 IAM、密钥管理、日志平台、监控告警、备份恢复和容灾设施，并完成容量压测、安全测试及业务 UAT。

## 生产执行一致性

`ProductionOrder` 保存当前受控状态与累计数量，`ProductionEvent` 保存每次报工事实。报工在单一数据库事务内锁定订单、写入幂等事件、累计数量并登记审计；悲观行锁串行化同一订单的并发报工，订单版本号防止其他更新丢失，事件键唯一约束处理终端重试。对接 ERP、MES 或设备终端时，应由适配器生成稳定的 `eventKey`，并基于 HTTP 409 执行业务补偿，不在客户端绕过状态机。
