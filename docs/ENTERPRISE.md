# 制造运营管理系统企业能力

## 领域覆盖

- **制造主数据**：维护工厂、产线、工作中心、工艺路线、班次与计量规则
- **生产订单**：承接计划订单并控制版本、优先级、批次与交期
- **排产与派工**：按产能、物料和设备状态下达工单与工序任务
- **工序执行**：执行开工、暂停、完工、返工和报废等现场事务
- **在制品管理**：跟踪批次、序列号、工位、数量与冻结状态
- **物料消耗**：记录领料、投料、替代、退料和消耗差异
- **质量关卡**：关联首检、巡检、末检、不合格和放行结果
- **设备与安灯**：采集运行停机、异常呼叫、响应、恢复与停机原因
- **班次交接**：交接产量、异常、待办、物料、设备和安全事项
- **制造追溯**：建立投入批次、工序、设备、人员与产出序列号谱系
- **制造绩效**：分析产量、达成率、一次合格率、损失时间和OEE

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对制造运营管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `ERP_MES_IOT`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
