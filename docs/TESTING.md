# 制造运营管理系统测试说明

后端测试覆盖：

1. 产品元数据、健康检查、未登录拦截、目录和看板；
2. 创建、修改、删除、重复编号、非法模块与服务端状态机；
3. 角色权限、管理员设置、操作审计、评论与时间线；
4. 组合检索、分页、SLA统计和CSV导出；
5. 企业控制项幂等、职责分离、审批、附件凭证、办结和外部回执；
6. 制造运营管理系统专属领域决策、指标、评分和认证要求；
7. prod profile 默认凭据和跨域安全门禁。
8. 生产订单创建、物料齐套、管理员下达、开工、暂停、恢复、报工、质量放行和完工关账；
9. 报工幂等重试、全局事件键冲突、超计划报工、报废原因必填、安灯阻断和未放行禁止完工；
10. 生产驾驶舱汇总、关键词检索、异常过滤和生产事件追溯。

执行命令：

```bash
cd backend && mvn test
cd ../frontend && npm ci && npm run build
docker compose config
```

测试数据库使用 H2；生产数据库为 MySQL 8。CI 使用 Java 21 与 Node LTS。自动化测试通过不替代生产容量测试、并发压测、渗透测试、灾备演练和业务 UAT。
